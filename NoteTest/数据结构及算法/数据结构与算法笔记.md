## 第 1 章 复杂度分析

### 核心概念

- **时间复杂度**：算法执行次数随输入规模 n 增长的量级，只保留最高阶项、忽略常数。
- **空间复杂度**：额外占用的存储随 n 的增长量级（不含输入本身）。
- 常见量级排序：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)

### 关键结论

| 场景 | 复杂度 |
| --- | --- |
| 数组随机访问 | O(1) |
| 有序数组二分查找 | O(log n) |
| 比较排序下界 | Ω(n log n) |
| 哈希表平均查找 | O(1)，最坏 O(n) |
| 快排平均 / 最坏 | O(n log n) / O(n²) |

- **均摊分析**：动态数组扩容虽然单次 O(n)，但均摊到每次 push 是 O(1)。
- **主定理**：T(n) = aT(n/b) + f(n)，用于分治复杂度估算。

### 常见坑

- 只算循环层数不看循环边界，`for (i = 1; i < n; i *= 2)` 是 O(log n) 不是 O(n)。
- 递归的空间复杂度要算栈深度。

## 第 2 章 线性结构

### 数组与链表

| 操作 | 数组 | 链表 |
| --- | --- | --- |
| 随机访问 | O(1) | O(n) |
| 头部插入 | O(n) | O(1) |
| 尾部插入 | 均摊 O(1) | O(1)（有尾指针） |
| 中间删除 | O(n) | O(1)（已知前驱） |

- 链表变体：单链表、双向链表、循环链表、静态链表（数组模拟）。
- **哨兵节点**能消掉大量边界判断，写链表题优先考虑。

### 栈与队列

- 栈：后进先出。应用——括号匹配、表达式求值、函数调用栈、单调栈。
- 队列：先进先出。应用——BFS、任务调度、滑动窗口。
- 变体：双端队列（deque）、优先队列（本质是堆）、循环队列（用取模避免搬移）。

### 常见坑

- 链表删除忘记保存 next 指针，导致断链。
- 循环队列的判空和判满条件要区分（通常牺牲一个空位）。

## 第 3 章 树

### 二叉树

- 遍历：前序（根左右）、中序（左根右）、后序（左右根）、层序（BFS）。
- **中序遍历二叉搜索树得到有序序列**，这是最常用的性质。
- 由「前序 + 中序」或「后序 + 中序」可唯一还原二叉树；「前序 + 后序」不行。

### 二叉搜索树（BST）

- 左子树全部小于根，右子树全部大于根。
- 查找/插入/删除平均 O(log n)，退化成链表时 O(n)。
- 删除分三种情况：叶子、单孩子、双孩子（用后继或前驱替换）。

### 平衡树

| 结构 | 特点 | 适用 |
| --- | --- | --- |
| AVL | 严格平衡，旋转多 | 查询多、更新少 |
| 红黑树 | 近似平衡，更新快 | 通用（Java TreeMap、C++ map） |
| B / B+ 树 | 多叉、矮胖 | 磁盘索引、数据库 |
| 跳表 | 概率平衡，实现简单 | Redis zset |
| Trie | 前缀共享 | 字典、自动补全 |

### 堆

- 完全二叉树 + 堆序性质，用数组存储：父 i，左 2i+1，右 2i+2。
- 建堆 O(n)，插入/弹出 O(log n)。
- 应用：优先队列、TopK、定时器、合并 K 个有序链表。

### 常见坑

- 堆的删除只能删堆顶；要删任意元素需要额外索引。
- BST 删除时用后继替换后，别忘了递归删除后继节点。

## 第 4 章 图

### 存储方式

- 邻接矩阵：O(V²) 空间，适合稠密图、需要 O(1) 判断边。
- 邻接表：O(V+E) 空间，适合稀疏图、遍历。
- 链式前向星：竞赛常用，省内存。

### 遍历

- DFS：递归或显式栈，适合连通性、拓扑排序、环检测。
- BFS：队列，适合无权图最短路、层次遍历。

### 经典算法

| 问题 | 算法 | 复杂度 |
| --- | --- | --- |
| 单源最短路（非负权） | Dijkstra + 堆 | O((V+E) log V) |
| 单源最短路（含负权） | Bellman-Ford / SPFA | O(VE) |
| 多源最短路 | Floyd | O(V³) |
| 最小生成树 | Kruskal（并查集）/ Prim（堆） | O(E log E) |
| 拓扑排序 | Kahn（入度）/ DFS 逆序 | O(V+E) |
| 强连通分量 | Tarjan / Kosaraju | O(V+E) |

### 常见坑

- Dijkstra 不能处理负权边。
- 拓扑排序有环时输出数量小于顶点数，可用来判环。
- 无向图存边要存双向，注意重边和自环。

## 第 5 章 排序

| 算法 | 平均 | 最坏 | 空间 | 稳定 |
| --- | --- | --- | --- | --- |
| 冒泡 | O(n²) | O(n²) | O(1) | 是 |
| 插入 | O(n²) | O(n²) | O(1) | 是 |
| 选择 | O(n²) | O(n²) | O(1) | 否 |
| 归并 | O(n log n) | O(n log n) | O(n) | 是 |
| 快排 | O(n log n) | O(n²) | O(log n) | 否 |
| 堆排 | O(n log n) | O(n log n) | O(1) | 否 |
| 计数/基数 | O(n+k) | O(n+k) | O(k) | 是 |

- 快排优化：三数取中、小区间插排、三路划分处理重复元素。
- 稳定性只在多关键字排序时才重要（例如先按分数再按年龄）。

## 第 6 章 查找与哈希

- 顺序查找 O(n)、二分查找 O(log n)（要求有序且支持随机访问）。
- 二分变体要背：找第一个 ≥ x、找最后一个 ≤ x、旋转数组找最小值。
- 哈希冲突处理：链地址法、开放寻址（线性探测、二次探测、双重哈希）。
- 负载因子过高要扩容；扩容时全部重哈希，代价均摊 O(1)。
- 一致性哈希：解决分布式缓存节点增减时的大面积失效。

## 第 7 章 算法思想

### 递归与分治

- 递归三要素：终止条件、递推关系、每层规模缩小。
- 分治典型：归并排序、快排、二分、大整数乘法、最近点对。

### 贪心

- 每步取局部最优，要求**贪心选择性质 + 最优子结构**。
- 典型：区间调度、哈夫曼编码、找零（特定面额）、最小生成树。

### 动态规划

- 三要素：状态定义、状态转移方程、边界条件。
- 判断能否 DP：重叠子问题 + 最优子结构。
- 常见模型：背包（01/完全/多重）、最长公共子序列、最长递增子序列、区间 DP、树形 DP、状压 DP。
- 优化手段：滚动数组、前缀和、单调队列、斜率优化。

### 回溯

- 本质是带剪枝的穷举，模板：选择 → 递归 → 撤销选择。
- 典型：全排列、组合、N 皇后、数独、子集。

### 常见坑

- DP 状态定义含糊，导致转移写不出来——先把「dp[i] 表示什么」用一句话写清楚。
- 回溯忘记恢复现场，结果越搜越少。
