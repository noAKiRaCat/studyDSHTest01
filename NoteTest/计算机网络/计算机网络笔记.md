# 计算机网络笔记

> 按 TCP/IP 分层组织：每章讲清「这一层解决什么问题、有哪些协议、容易错在哪」。
> 面试高频集中在传输层和 HTTP，工程实践集中在网络层与排障。

---

## 第 1 章 概述与体系结构

- 三种模型：OSI 七层、TCP/IP 四层、五层教学模型。
- 分层好处：各层独立演进，上层不关心下层实现。
- 核心指标：带宽、时延（发送 + 传播 + 处理 + 排队）、往返时间 RTT、吞吐量。
- 时延带宽积 = 带宽 × 传播时延，决定「管道里能装多少数据」。
- 封装与解封装：每层加首部，接收端逐层剥离。

---

## 第 2 章 物理层

- 作用：在传输媒体上传比特流。
- 编码：曼彻斯特编码（自同步）、4B/5B、NRZ。
- 调制：ASK、FSK、PSK、QAM。
- 传输媒体：双绞线（Cat5e/6）、同轴、光纤（单模/多模）、无线。
- 信道复用：频分、时分、波分、码分。
- 香农定理与奈奎斯特准则决定信道极限速率。

---

## 第 3 章 数据链路层

- 三大功能：封装成帧、差错控制、流量控制。
- 成帧方法：字符计数、字节填充、比特填充、违规编码。
- 差错检测：奇偶校验、CRC（检错不纠错）、海明码（可纠错）。
- 可靠传输：停止等待、后退 N 帧（GBN）、选择重传（SR）。
- **CSMA/CD**（以太网，半双工）与 **CSMA/CA**（无线，避免冲突）。
- 以太网帧：目的 MAC + 源 MAC + 类型 + 数据 + FCS，MTU 通常 1500 字节。
- 交换机：自学习 MAC 地址表，冲突域隔离；VLAN 做广播域隔离。
- PPP 协议用于点对点链路。

---

## 第 4 章 网络层

### IP

- IPv4 首部 20 字节起，关键字段：TTL、协议、分片偏移、校验和。
- 分类地址 → 子网掩码 → CIDR（无类域间路由）。
- 私有地址段：10/8、172.16/12、192.168/16；NAT 做地址转换。
- 分片与重组：MTU 超限时在路由器分片，DF 位禁止分片。
- IPv6：128 位，取消首部校验和，简化分片，内置地址自动配置。

### 路由

- 路由表匹配原则：**最长前缀匹配**。
- 路由协议：
  - 内部网关：RIP（距离向量，跳数）、OSPF（链路状态，Dijkstra）；
  - 外部网关：BGP（路径向量，策略路由）。
- ARP：IP → MAC，广播请求、单播应答，有缓存。
- ICMP：差错报告与探测，`ping` 用 Echo，`traceroute` 用 TTL 递增。
- DHCP：动态分配 IP，DORA 四步（Discover/Offer/Request/Ack）。

## 第 5 章 传输层

### UDP

- 无连接、不可靠、首部仅 8 字节，适合实时音视频、DNS、游戏。
- 没有拥塞控制，所以延迟低但可能加剧网络拥塞。

### TCP

- 面向连接、可靠、字节流、全双工。
- **三次握手**：SYN → SYN+ACK → ACK；目的是同步序列号并确认双方收发能力。
- **四次挥手**：FIN → ACK → FIN → ACK；主动关闭方进入 TIME_WAIT（2MSL）。
- 为什么 TIME_WAIT 要等 2MSL：保证最后的 ACK 能被对端收到，并让旧连接报文消散。
- 可靠传输：序号 + 确认 + 超时重传 + 快速重传（三个重复 ACK）。
- 流量控制：滑动窗口，接收方通过窗口字段告诉发送方能收多少。
- **拥塞控制**：慢启动（指数增长）→ 拥塞避免（线性增长）→ 快重传 → 快恢复。
- 常见拥塞控制算法：Reno、CUBIC、BBR（基于带宽和 RTT 建模）。

### 易错点

- 三次握手不能改成两次：无法防止历史重复连接请求。
- SYN Flood 攻击利用半连接队列，防御手段是 SYN Cookie。

## 第 6 章 应用层

### HTTP

- 请求/响应模型，无状态（靠 Cookie/Session/Token 维持状态）。
- 方法：GET、POST、PUT、PATCH、DELETE、HEAD、OPTIONS。
- 状态码：2xx 成功、3xx 重定向、4xx 客户端错、5xx 服务端错。
- HTTP/1.1：长连接、管道化（实际很少用）、队头阻塞。
- HTTP/2：二进制分帧、多路复用、头部压缩（HPACK）、服务端推送。
- HTTP/3：基于 QUIC（UDP），解决 TCP 队头阻塞，0-RTT 建连。
- HTTPS = HTTP + TLS：非对称握手协商密钥，对称加密传数据，证书链验证身份。

### DNS

- 递归查询 vs 迭代查询；根 → 顶级域 → 权威服务器。
- 记录类型：A、AAAA、CNAME、MX、TXT、NS。
- 缓存与 TTL 决定解析速度和生效时间。

### 其他

- WebSocket：一次握手后全双工，适合推送。
- CDN：就近缓存静态资源，靠 DNS 调度。
- 邮件：SMTP 发送、POP3/IMAP 收取。

---

## 第 7 章 网络安全

- 加密：对称（AES，快）与非对称（RSA/ECC，用于密钥交换和签名）。
- 哈希：MD5/SHA-1 已不安全，用 SHA-256；加盐防彩虹表。
- 数字签名 = 私钥签名 + 公钥验签，保证完整性与不可否认。
- 常见攻击：中间人、重放、SQL 注入、XSS、CSRF、DDoS。
- 防护：TLS、输入校验、CSP、CSRF Token、限流与 WAF。

---

## 第 8 章 无线与移动网络

- 802.11 系列：2.4G/5G/6G 频段，信道划分，隐藏终端问题。
- CSMA/CA + ACK 确认；RTS/CTS 缓解隐藏终端。
- 移动 IP：归属代理与外部代理，三角路由问题。
- 4G/5G 核心网：控制面与用户面分离（CUPS），网络切片。

## 排障清单

```bash
ping 8.8.8.8            # 通不通，看丢包和 RTT
tracert example.com     # 在哪一跳断的
nslookup example.com    # 解析对不对
netstat -ano | findstr :80   # 端口有没有被占
curl -v https://example.com  # TLS 握手和响应头
```

- 能 ping 通 IP 但域名不通 → DNS 问题。
- 能访问 IP 但端口不通 → 防火墙/安全组。
- 握手成功但很慢 → 看 TLS 版本、证书链、MTU。
