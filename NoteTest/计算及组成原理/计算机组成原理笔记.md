# 计算机组成原理笔记

> 按章节整理：核心概念 → 关键计算 → 易错点。
> 这门课的计算题（CPI、命中率、补码运算）必须动手算，光看公式没用。

---

## 第 1 章 计算机系统概述

- 冯·诺依曼结构五大部件：运算器、控制器、存储器、输入设备、输出设备；核心思想是**存储程序**。
- 层次结构：硬件 → 操作系统 → 语言处理 → 应用程序。
- 性能指标：
  - **CPI**（每条指令平均时钟周期数）
  - **主频 f**，CPU 时间 = 指令数 × CPI ÷ f
  - **MIPS** = 指令数 / (执行时间 × 10⁶) = f / (CPI × 10⁶)
  - **MFLOPS** 衡量浮点性能
- Amdahl 定律：系统加速受限于不可优化部分。

---

## 第 2 章 数据的表示与运算

### 数制与编码

- 二进制、八进制、十六进制互转；8421 BCD 码。
- 真值 vs 机器数；原码、反码、补码、移码。
- **补码**：正数同原码，负数 = 反码 + 1；补码能把减法变加法，且 0 的表示唯一。

### 定点运算

- 补码加减法：符号位参与运算，溢出用**双符号位**或「同号相加结果异号」判断。
- 移位：算术右移补符号位，逻辑右移补 0。

### 浮点运算

- IEEE 754 单精度：1 位符号 + 8 位阶码（偏置 127）+ 23 位尾数；
  双精度：1 + 11（偏置 1023）+ 52。
- 规格化数隐含前导 1；阶码全 0 表示非规格化，全 1 表示无穷/NaN。
- 浮点加减步骤：对阶（小阶向大阶看齐）→ 尾数求和 → 规格化 → 舍入 → 溢出判断。
- 舍入方式：就近舍入（默认）、朝零、朝正无穷、朝负无穷。

### 易错点

- 溢出的判断只看数值范围，不看符号位本身。
- 对阶时尾数右移会丢精度，这是浮点误差的根源。

## 第 3 章 存储系统

### 层次结构

寄存器 → Cache → 主存 → 辅存，速度递减、容量递增、单位成本递减。

### 主存

- SRAM（快、贵、不需刷新）用于 Cache；DRAM（慢、便宜、需刷新）用于主存。
- 刷新方式：集中刷新、分散刷新、异步刷新。
- 存储芯片扩展：位扩展（加字长）、字扩展（加容量）、字位同时扩展。

### Cache

- 映射方式：直接映射、全相联、组相联（折中，最常用）。
- 地址划分：标记 + 组号 + 块内地址。
- 替换算法：随机、FIFO、LRU、LFU。
- 写策略：写直达 + 非写分配；写回 + 写分配。
- **平均访问时间** = 命中率 × 命中时间 + 缺失率 × 缺失代价。
- 局部性原理是 Cache 有效的前提。

### 虚拟存储器

- 页式虚拟存储，页表 + TLB；缺页中断由操作系统处理。
- 虚拟地址 → 物理地址转换；TLB 命中可跳过页表访问。

### 易错点

- 计算 Cache 行数、组数时单位换算（KB、块大小、字长）最易错。
- 写回策略下，脏块被替换时才写回主存。

## 第 4 章 指令系统

- 指令格式：操作码 + 地址码；定长 vs 变长。
- 寻址方式：立即、直接、间接、寄存器、寄存器间接、变址、基址、相对、堆栈。
- **有效地址**的计算是高频考点。
- CISC（复杂指令、变长、微程序控制）vs RISC（精简、定长、硬布线、流水线友好、寄存器多）。
- 指令流水线：取指 IF → 译码 ID → 执行 EX → 访存 MEM → 写回 WB。
- 流水线性能：理想加速比 ≈ 流水段数；实际受冒险影响。

---

## 第 5 章 中央处理器

- CPU = 运算器（ALU + 寄存器）+ 控制器（PC、IR、时序、微操作）。
- 数据通路：单总线、多总线、专用通路。
- 控制器两种实现：
  - **硬布线**：速度快、不灵活；
  - **微程序**：灵活、易扩展，用控制存储器存微指令。
- 微指令格式：水平型（并行度高、字长）、垂直型（串行、字短）。
- 指令周期：取指 → 间址 → 执行 → 中断，各阶段由机器周期组成。
- 中断：响应条件、中断向量、中断优先级、中断嵌套。

---

## 第 6 章 总线

- 分类：片内总线、系统总线（数据/地址/控制）、通信总线。
- 性能指标：总线宽度、总线频率、带宽 = 宽度 × 频率 / 8。
- 仲裁：集中式（链式查询、计数器定时、独立请求）与分布式。
- 定时：同步（统一时钟）与异步（握手）。
- 常见标准：PCIe、USB、SATA、NVMe（走 PCIe）。

---

## 第 7 章 输入输出系统

- I/O 编址：统一编址（内存映射）与独立编址。
- 三种 I/O 方式：
  - **程序查询**：CPU 忙等，效率最低；
  - **中断**：CPU 不用等，但每次传送都要打断；
  - **DMA**：成块传送，CPU 只在开始和结束时介入。
- 中断处理流程：关中断 → 保存断点 → 识别中断源 → 保护现场 → 服务 → 恢复现场 → 开中断 → 返回。
- 磁盘：寻道时间 + 旋转延迟 + 传输时间；RAID 0/1/5/10 的容量与容错取舍。

---

## 第 8 章 流水线与并行

- 流水线冒险：
  - 结构冒险——资源冲突；
  - 数据冒险——RAW 最常见，用转发或停顿；
  - 控制冒险——分支，用预测 + 延迟槽。
- 超标量（多条流水线并行）、超流水线（细分段）、动态调度（乱序执行）。
- 多核与 SMT（超线程）：共享执行单元，提升吞吐而非单线程性能。
- GPU：SIMT 模型，适合数据并行；与 CPU 的分工是「延迟优化 vs 吞吐优化」。
