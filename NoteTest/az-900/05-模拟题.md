# AZ-900 模拟题（40 题）

> 按考试三个领域配比编写：云概念 12 题、架构与服务 16 题、管理与治理 12 题。
> 答案与解析在文末；建议第一遍不计时，第二遍 45 分钟内做完。

## 一、云概念（12 题）

**1.** 一家公司把自建机房迁到 Azure 后，服务器采购从一次性投入变成按月付费，这体现的是？
1. CapEx 转 OpEx　2. 高可用性　3. 弹性伸缩　4. 混合云

**2.** 「需求增加时自动增加 VM 数量，需求下降时减少」属于？
1. 纵向扩展　2. 横向扩展　3. 区域冗余　4. 故障转移

**3.** 把单台 VM 从 2 核 8GB 升级到 8 核 32GB，属于？
1. Scale out　2. Scale up　3. Scale in　4. Scale down

**4.** 在 SaaS 模型中，客户仍然负责以下哪一项？
1. 操作系统补丁　2. 运行时环境　3. 用户数据与访问管理　4. 物理服务器

**5.** 以下哪项**不是**云计算的典型特征？
1. 按需自助服务　2. 资源池化　3. 必须签三年合同　4. 计量付费

**6.** 混合云最核心的特征是？
1. 使用两家云厂商　2. 公有云与私有云之间数据和身份可以打通
3. 全部资源都在本地　4. 只用 PaaS

**7.** 某公司要求核心数据留在本地机房，前端网站放在公有云，这属于？
1. 公有云　2. 私有云　3. 混合云　4. 社区云

**8.** 「按执行次数计费、不需管理服务器」的计算模型是？
1. IaaS　2. PaaS　3. Serverless　4. 专用主机

**9.** 以下哪个是 PaaS 服务？
1. Azure 虚拟机　2. Azure App Service　3. Azure 托管磁盘　4. Azure VPN 网关

**10.** 可用性 99.9% 大约意味着一年不可用时间是多少？
1. 约 8.76 小时　2. 约 52 分钟　3. 约 5 分钟　4. 约 3.65 天

**11.** 云服务商负责物理机房安全，客户负责账户与数据安全，这一概念叫？
1. 服务级别协议　2. 责任共担模型　3. 零信任　4. 合规性

**12.** 以下哪项最能说明「弹性」与「可伸缩」的差别？
1. 弹性只能扩不能缩　2. 可伸缩指能力可放大缩小，弹性强调自动化与双向
3. 两者完全等价　4. 弹性只适用于存储

## 二、架构与服务（16 题）

**13.** 一个资源最多可以属于几个资源组？
1. 1 个　2. 2 个　3. 不限　4. 取决于订阅类型

**14.** 用于在同一区域内提供物理隔离的数据中心组的是？
1. 区域对　2. 可用性区域　3. 资源组　4. 管理组

**15.** 关于资源组，正确的是？
1. 资源组必须与资源在同一区域　2. 资源组可以包含不同区域的资源
3. 删除资源组不会删除其中的资源　4. 一个资源可属于多个资源组

**16.** 想在不暴露公网 IP 的情况下通过浏览器连接 VM，应使用？
1. Azure Bastion　2. NSG　3. ExpressRoute　4. Azure Firewall

**17.** 需要专用线路连接本地机房与 Azure，且流量不经过公网，应选？
1. 站点到站点 VPN　2. ExpressRoute　3. 点对站点 VPN　4. Azure DNS

**18.** 哪种存储适合存放大量非结构化图片与视频？
1. Azure Files　2. Blob Storage　3. Managed Disks　4. Queue Storage

**19.** Blob 的哪种冗余会在配对区域保留副本？
1. LRS　2. ZRS　3. GRS　4. 单副本

**20.** 长期归档、几乎不访问的数据应放哪个访问层？
1. Hot　2. Cool　3. Cold　4. Archive

**21.** 需要把 50 TB 数据从本地一次性搬到 Azure，网络带宽有限，最合适的是？
1. AzCopy　2. Azure Data Box　3. Storage Explorer　4. File Sync

**22.** NSG 的默认行为是？
1. 允许所有入站与出站　2. 拒绝所有入站，允许出站
3. 拒绝所有出站　4. 全部拒绝

**23.** 以下哪项是 Platform as a Service 的容器托管方案，且控制面免费？
1. ACI　2. AKS　3. VMSS　4. App Service

**24.** 想让应用在没有服务器管理的情况下按 HTTP 请求触发执行，应选？
1. Azure Functions　2. Azure VM　3. AKS　4. Virtual Desktop

**25.** 关于 Microsoft Entra ID，正确的是？
1. 它是本地 AD 的替代品，只能同步用户　2. 提供 SSO、MFA、条件访问等云身份能力
3. 只能管理 Windows 设备　4. 不能与本地 AD 集成

**26.** 希望授予某用户「只能读、不能改」的权限，应分配哪个内置角色？
1. Owner　2. Contributor　3. Reader　4. User Access Administrator

**27.** 让 VM 无需存储密钥即可访问 Key Vault，最佳做法是？
1. 把密钥写进代码　2. 使用托管标识　3. 使用共享密钥　4. 开放 Key Vault 公网访问

**28.** 检测并阻止向非允许区域创建资源，应使用？
1. RBAC　2. Azure Policy　3. 资源锁　4. NSG

## 三、管理与治理（12 题）

**29.** 上线前估算每月 Azure 花费，应使用？
1. TCO 计算器　2. 定价计算器　3. Cost Management　4. Advisor

**30.** 比较「继续用本地机房」与「迁移到 Azure」的三年总成本，应使用？
1. 定价计算器　2. TCO 计算器　3. 成本分析　4. 预算

**31.** 防止误删生产资源组，最直接的做法是？
1. 加 Reader 角色　2. 加 CanNotDelete 资源锁　3. 加策略 Audit　4. 开诊断日志

**32.** 资源锁与 RBAC 的关系是？
1. 锁只对 Reader 生效　2. 锁优先于 RBAC，Owner 也无法删除被锁资源
3. 锁只对资源组生效　4. 两者等价

**33.** 想让新订阅自动带上「必须打标签」的规则，应使用？
1. 资源锁　2. Azure Policy　3. NSG　4. Advisor

**34.** ARM 模板默认的部署模式是？
1. 完整（Complete）　2. 增量（Incremental）　3. 覆盖　4. 只读

**35.** 哪种部署模式会删除模板中未定义的现有资源？
1. 增量　2. 完整　3. 验证　4. 计划

**36.** 查看 Azure 平台侧的服务中断公告，应看？
1. Resource Health　2. Service Health　3. Advisor　4. Monitor

**37.** 想知道某台 VM 当前是否可用（是否被平台维护影响），应看？
1. Service Health　2. Resource Health　3. 活动日志　4. 成本分析

**38.** 用于查询日志的 KQL 在哪个组件里执行？
1. Application Insights　2. Log Analytics　3. Advisor　4. Policy

**39.** 给出「降低成本、提升安全」等建议但不自动修复的是？
1. Azure Advisor　2. Azure Policy　3. Defender for Cloud　4. Monitor

**40.** 把本地服务器纳入 Azure 统一管理，应使用？
1. Azure Arc　2. Azure Bastion　3. ExpressRoute　4. Azure Migrate
