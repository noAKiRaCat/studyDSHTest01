# 术语速查表

> 考前一天刷这个。左边是中文，右边是考试里会出现的英文原词。

## 云概念

| 中文 | 英文 | 一句话 |
| --- | --- | --- |
| 资本支出 | CapEx | 买硬件，一次性投入 |
| 运营支出 | OpEx | 按用量付费，持续支出 |
| 按需自助服务 | On-demand self-service | 自己开通，不用审批 |
| 资源池化 | Resource pooling | 多租户共享资源池 |
| 弹性 | Elasticity | 能自动扩也能自动缩 |
| 纵向扩展 | Scale up | 加 CPU/内存 |
| 横向扩展 | Scale out | 加机器数量 |
| 高可用 | High availability | 故障时仍可用 |
| 容灾 | Disaster recovery | 大故障后恢复 |
| 责任共担 | Shared responsibility model | 越 SaaS 客户管得越少 |
| 无服务器 | Serverless | 不关心服务器，按执行付费 |
| 混合云 | Hybrid cloud | 公有 + 私有，数据身份打通 |

## 架构

| 中文 | 英文 | 一句话 |
| --- | --- | --- |
| 区域 | Region | 地理区域 |
| 可用性区域 | Availability Zone | 同区域内物理隔离 |
| 区域对 | Region pair | 相距 300 英里以上 |
| 资源组 | Resource group | 资源逻辑容器，只能属于一个 |
| 订阅 | Subscription | 计费与配额边界 |
| 管理组 | Management group | 批量管订阅 |
| 虚拟网络 | VNet | 私有网络 |
| 网络安全组 | NSG | 子网/NIC 防火墙 |
| 专用终结点 | Private endpoint | PaaS 私有接入 |
| 快速路由 | ExpressRoute | 专线，不走公网 |
| 点对站点 VPN | Point-to-site VPN | 单机连入 VNet |
| 可用性集 | Availability set | 同一区域内防故障域 |
| 规模集 | VM Scale Set | 同构 VM 自动伸缩 |

## 存储

| 中文 | 英文 | 一句话 |
| --- | --- | --- |
| 块 blob | Block blob | 常规文件 |
| 页 blob | Page blob | VHD 磁盘 |
| 追加 blob | Append blob | 日志追加 |
| 热/冷/归档层 | Hot/Cool/Archive | 越冷越便宜，取回越贵 |
| 本地冗余 | LRS | 同机房三副本 |
| 区域冗余 | ZRS | 跨可用区 |
| 异地冗余 | GRS | 跨区域复制 |
| 只读异地冗余 | RA-GRS | 次要区域可读 |
| 共享访问签名 | SAS | 有时效的访问令牌 |

## 身份安全

| 中文 | 英文 | 一句话 |
| --- | --- | --- |
| 单点登录 | SSO | 一次登录多应用 |
| 多因素认证 | MFA | 密码 + 第二因素 |
| 条件访问 | Conditional Access | 按条件决定是否放行 |
| 基于角色的访问控制 | RBAC | 谁能做什么 |
| 托管标识 | Managed identity | 免密钥的服务身份 |
| 零信任 | Zero Trust | 永不信任，始终验证 |
| 密钥保管库 | Key Vault | 存密钥证书 |
| 安全信息和事件管理 | SIEM | Sentinel |

## 管理与治理

| 中文 | 英文 | 一句话 |
| --- | --- | --- |
| 策略 | Azure Policy | 资源必须长什么样 |
| 蓝图 | Blueprint | 打包策略+权限+模板 |
| 资源锁 | Resource lock | 防误删/防修改 |
| 总拥有成本 | TCO | 本地 vs 云 |
| 定价计算器 | Pricing calculator | 上线前估价 |
| 成本管理 | Cost Management | 上线后看账 |
| 增量部署 | Incremental | 只增改 |
| 完整部署 | Complete | 会删模板外资源 |
| 活动日志 | Activity log | 谁做了什么 |
| 服务健康 | Service Health | 平台侧故障 |
| 资源健康 | Resource Health | 资源自身状态 |
| 顾问 | Advisor | 优化建议 |

## 容易混淆的三组

| A | B | 区别 |
| --- | --- | --- |
| Azure Policy | RBAC | 管资源形态 vs 管人的权限 |
| Pricing Calculator | Cost Management | 预估 vs 实际账单 |
| Service Health | Resource Health | 微软平台 vs 你的资源 |
