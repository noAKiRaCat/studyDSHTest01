# OpenShift 常用命令速查

> 前缀 `oc`，绝大多数子命令和 `kubectl` 一致。下面按使用场景分组，标 ★ 的是天天要用的。

## 登录与环境

```bash
oc login https://api.example.com:6443 -u admin -p 'password'   # ★ 登录
oc login --token=sha256~xxxx --server=https://api.example.com:6443
oc whoami                                                       # ★ 当前用户
oc whoami --show-server                                         # 当前集群地址
oc whoami --show-console                                        # console 地址
oc logout
```

## 项目（Namespace）

```bash
oc new-project demo                       # ★ 新建项目并切过去
oc projects                               # 列出可访问的项目
oc project demo                           # ★ 切换项目
oc get project
oc delete project demo
```

## 查看资源

```bash
oc get pods                               # ★
oc get pods -o wide                       # 带 IP / 节点
oc get all -n demo                        # 该项目下大部分资源
oc get deploy,svc,route,pvc               # 一次看多类
oc describe pod mypod-xxx                 # ★ 排障第一步
oc get events --sort-by=.lastTimestamp    # ★ 最近发生了什么
oc explain deployment.spec.replicas       # 字段含义
oc api-resources                          # 集群支持哪些资源
```

## 创建与修改

```bash
oc apply -f app.yaml                      # ★ 声明式
oc create -f app.yaml
oc delete -f app.yaml
oc edit deployment/myapp                  # 直接改，保存即生效
oc set env deployment/myapp KEY=value     # ★ 改环境变量（会触发滚动）
oc set image deployment/myapp app=image:tag
oc scale deployment/myapp --replicas=3    # ★
oc rollout status deployment/myapp        # 看滚动进度
oc rollout undo deployment/myapp          # 回滚
oc rollout history deployment/myapp
```

## 从代码到应用

```bash
oc new-app https://github.com/user/repo.git --name=myapp   # ★ S2I 构建
oc new-app --docker-image=nginx:alpine
oc new-app --image-stream=openshift/nodejs:20 --code=https://github.com/user/repo.git
oc start-build myapp --from-dir=. --follow                  # 本地目录构建
oc logs -f bc/myapp                                         # 构建日志
```

## 暴露服务

```bash
oc expose service/myapp                   # ★ 生成 Route
oc expose service/myapp --host=app.example.com
oc create route edge myroute --service=myapp --host=app.example.com
oc get route                              # ★ 拿访问地址
oc port-forward pod/mypod 8080:8080       # 本地调试
```

## 进入容器 / 传文件

```bash
oc rsh pod/mypod                          # ★ shell 进去
oc exec -it pod/mypod -- /bin/sh
oc exec pod/mypod -- env
oc cp ./local.txt pod/mypod:/tmp/         # 拷贝文件
oc rsync ./dist pod/mypod:/opt/app-root/src/   # ★ 目录同步
oc debug deployment/myapp                 # 起一个调试副本
oc debug node/node-1                      # ★ 进节点排查
```

## 日志

```bash
oc logs pod/mypod                         # ★
oc logs -f pod/mypod -c sidecar           # 多容器指定容器
oc logs -f deployment/myapp               # 跟 Deployment
oc logs -f bc/myapp                       # 构建日志
oc adm node-logs node-1 --path=journal    # 节点日志
```

## 权限与安全

```bash
oc adm policy add-role-to-user view alice -n demo        # ★ 授权
oc adm policy add-role-to-user edit bob -n demo
oc adm policy add-cluster-role-to-user cluster-admin alice
oc adm policy add-scc-to-user anyuid -z default -n demo  # 慎用
oc auth can-i create pods -n demo                        # ★ 我有权限吗
oc auth can-i --list -n demo
oc get sa -n demo                                        # ServiceAccount
oc get scc                                               # 安全上下文约束
oc get rolebinding,clusterrolebinding -n demo
```

## 节点与集群

```bash
oc get nodes                              # ★
oc get nodes -o wide
oc adm top nodes                          # 资源占用
oc adm top pods -n demo
oc cordon node-1                          # 禁止调度
oc drain node-1 --ignore-daemonsets --delete-emptydir-data   # ★ 维护前腾空
oc uncordon node-1
oc get clusteroperators                   # ★ 集群组件健康
oc get clusterversion                    # 版本与升级状态
oc adm upgrade                           # 查看可用升级
oc get co -w                             # 升级时盯着
```

## 存储

```bash
oc get pv,pvc,sc
oc get pvc -n demo
oc patch pvc myclaim -p '{"spec":{"resources":{"requests":{"storage":"20Gi"}}}}'
```

## 镜像与 ImageStream

```bash
oc get imagestream
oc import-image myimg:1.0 --from=nginx:alpine --confirm
oc tag myimg:1.0 myimg:latest
oc get istag
```

## 排障套路（贴在显示器上）

```bash
# 1. 看状态
oc get pods
# 2. 看事件和原因
oc describe pod <pod>
oc get events --sort-by=.lastTimestamp | tail -20
# 3. 看日志
oc logs <pod> --previous
# 4. 进容器 / 调试
oc rsh <pod>
oc debug deployment/<name>
# 5. 看路由与网络
oc get route,svc,endpoints
# 6. 看配额和节点
oc get resourcequota,limitrange
oc adm top nodes
```

## 小抄

| 想做的事 | 命令 |
| --- | --- |
| 换项目 | `oc project <name>` |
| 看某资源 YAML | `oc get deploy myapp -o yaml` |
| 删不掉的 Pod | `oc delete pod <pod> --grace-period=0 --force` |
| 看容器镜像 | `oc get pods -o jsonpath='{.items[*].spec.containers[*].image}'` |
| 所有项目的事件 | `oc get events -A --sort-by=.lastTimestamp` |
| 进 etcd 备份 | `oc debug node/<node>` 后再 `chroot /host` |
