## 1. 短期记忆

短期记忆 = **同一次会话内的对话历史**，靠 checkpointer 持久化。

```python
from langgraph.checkpoint.memory import InMemorySaver
from langchain.agents import create_agent

agent = create_agent(
    model="openai:gpt-5.5",
    tools=tools,
    checkpointer=InMemorySaver(),
)

config = {"configurable": {"thread_id": "user-42"}}
agent.invoke({"messages": [{"role": "user", "content": "我叫小明"}]}, config=config)
agent.invoke({"messages": [{"role": "user", "content": "我叫什么？"}]}, config=config)
```

### 检查点选择

| 实现 | 包 | 场景 |
|---|---|---|
| `InMemorySaver` | 内置 | 开发、测试 |
| `SqliteSaver` | `langgraph-checkpoint-sqlite` | 单机持久化 |
| `PostgresSaver` | `langgraph-checkpoint-postgres` | 生产、多实例 |

```python
from langgraph.checkpoint.postgres import PostgresSaver

with PostgresSaver.from_conn_string("postgresql://...") as cp:
    cp.setup()   # 首次运行建表
    agent = create_agent(model="...", tools=tools, checkpointer=cp)
```

### 历史压缩

长会话会撑爆上下文，用摘要中间件：

```python
from langchain.agents.middleware import SummarizationMiddleware

agent = create_agent(
    model="openai:gpt-5.5",
    tools=tools,
    middleware=[SummarizationMiddleware(max_tokens=6000, keep_last=10)],
)
```

策略：保留最近 N 条原文，更早的压缩成一段摘要。

## 2. 长期记忆

长期记忆 = **跨会话**保留的信息（偏好、事实、约定），存在 `Store` 里。

```python
from langgraph.store.memory import InMemoryStore
from langchain.agents import create_agent

store = InMemoryStore()

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[save_preference, recall_preference],
    store=store,
)
```

在工具里读写：

```python
from langchain.tools import tool, ToolRuntime


@tool
def save_preference(key: str, value: str, runtime: ToolRuntime) -> str:
    """保存用户偏好，例如 key='语言', value='中文'。"""
    user_id = runtime.context.user_id
    runtime.store.put(("preferences", user_id), key, {"value": value})
    return f"已记住：{key} = {value}"


@tool
def recall_preference(key: str, runtime: ToolRuntime) -> str:
    """读取用户偏好。"""
    user_id = runtime.context.user_id
    item = runtime.store.get(("preferences", user_id), key)
    return item.value["value"] if item else "未记录"
```

**语义检索**：`Store` 支持向量索引，适合「按意思找记忆」：

```python
store = InMemoryStore(index={"embed": embeddings, "dims": 1536})
store.put(("memories", "u1"), "m1", {"text": "用户喜欢简洁回答"})
hits = store.search(("memories", "u1"), query="回答风格")
```

## 3. 流式输出

### 3.1 四种模式

```python
for mode in ["values", "updates", "messages", "custom"]:
    print(f"--- {mode} ---")
```

| 模式 | 得到什么 | 适合 |
|---|---|---|
| `values` | 每步完整状态 | 调试、快照 |
| `updates` | 每步增量 | 状态可视化 |
| `messages` | `(token, metadata)` 元组 | 打字机效果 |
| `custom` | 自定义 `StreamWriter` 写入的事件 | 业务进度 |

### 3.2 打字机效果

```python
for token, metadata in agent.stream(
    {"messages": [{"role": "user", "content": "写一首关于秋天的诗"}]},
    stream_mode="messages",
):
    if token.content:
        print(token.content, end="", flush=True)
```

### 3.3 自定义进度

```python
from langgraph.config import get_stream_writer

@tool
def long_task(n: int) -> str:
    """模拟一个长任务。"""
    writer = get_stream_writer()
    for i in range(n):
        writer({"progress": (i + 1) / n, "step": i})
    return "完成"

# 消费端
for event in agent.stream(..., stream_mode="custom"):
    print(event)
```

### 3.4 同时订阅多种模式

```python
for mode, chunk in agent.stream(..., stream_mode=["messages", "updates"]):
    print(mode, chunk)
```

## 4. 多智能体架构

### 4.1 子代理（Subagents）

主代理把子任务派给子代理，子代理在**独立上下文**里跑完，只回传一份结论。

```python
from langchain.agents import create_agent
from langchain.tools import tool


@tool
def research(topic: str) -> str:
    """调用研究子代理深入调研某个主题。"""
    sub = create_agent(
        model="anthropic:claude-sonnet-5",
        tools=[web_search, read_pdf],
        system_prompt="你是研究员，负责调研并给出结构化结论。",
    )
    result = sub.invoke({"messages": [{"role": "user", "content": topic}]})
    return result["messages"][-1].text


main = create_agent(
    model="openai:gpt-5.5",
    tools=[research, write_report],
    system_prompt="你是项目负责人，把调研交给 research，把撰写交给 write_report。",
)
```

**好处**：主代理上下文干净、子任务可并行、可给不同子代理不同模型与工具。

### 4.2 交接（Handoffs）

一个 Agent 把控制权交给另一个，通常用于客服分流：

```python
from langchain.agents import create_agent
from langchain.tools import tool

def make_handoff(target_agent, description: str):
    @tool(description=description)
    def handoff(reason: str) -> str:
        """把对话移交给目标代理。"""
        return f"HANDOFF::{target_agent.name}::{reason}"
    return handoff

billing = create_agent(model="openai:gpt-5.5", tools=[refund], name="billing")
tech = create_agent(model="openai:gpt-5.5", tools=[reset_password], name="tech")

triage = create_agent(
    model="openai:gpt-5.5",
    tools=[
        make_handoff(billing, "涉及账单、退款、发票时使用"),
        make_handoff(tech, "涉及登录、密码、故障时使用"),
    ],
    name="triage",
)
```

生产环境一般用 LangGraph 的 `Command(goto=...)` 做真正的图级交接（见 LangGraph 篇）。

### 4.3 路由（Router）

按输入类型分发到不同的专家链：

```python
from langgraph.graph import StateGraph, MessagesState, START, END

def classify(state: MessagesState) -> str:
    """用便宜模型做一次分类。"""
    ...

builder = StateGraph(MessagesState)
builder.add_node("classify", classify_node)
builder.add_node("sql_expert", sql_agent)
builder.add_node("doc_expert", doc_agent)
builder.add_conditional_edges("classify", classify, {
    "sql": "sql_expert",
    "doc": "doc_expert",
})
```

### 4.4 三种模式对比

| 模式 | 控制流 | 上下文 | 适合 |
|---|---|---|---|
| 子代理 | 主代管理，调用即返回 | 隔离 | 并行调研、长任务 |
| 交接 | 控制权转移 | 可共享 | 客服分流、专业转接 |
| 路由 | 一次性分发 | 独立 | 意图明确的多专家 |

## 6. 常见坑

| 现象 | 原因 | 解决 |
|---|---|---|
| 记忆丢失 | 换了 `thread_id` | 前端要稳定保存会话 ID |
| 长期记忆查不到 | 用了 `get` 但 key 拼错 | 统一 key 规范（命名空间 + ID） |
| 流式无输出 | 模型不支持或未开 `streaming` | 换模型或检查网关 |
| 子代理超时 | 没有超时控制 | 中间件加 timeout |
| 交接后状态错乱 | 共享了 checkpointer 但没隔离 thread | 交接时新建子 thread |
