# LangChain 01 · 快速开始与安装

> LangChain v1 的核心只有一个函数：`create_agent`。它给出一个最小但高度可配置的 Agent 骨架。

---

## 1. 安装

```bash
# 核心包
pip install -U langchain

# 按需安装模型供应商的独立包（v1 起供应商集成不在主包里）
pip install -U "langchain[openai]"
pip install -U "langchain[anthropic]"
pip install -U "langchain[google-genai]"

# 本地模型
pip install -U langchain-ollama
```

用 `uv` 的话：

```bash
uv add langchain "langchain[openai]"
```

**v1 的重要变化**：模型集成被拆成独立发行包，装 `langchain` 本身不会带上 OpenAI/Anthropic 的 SDK，必须显式安装 `langchain-openai` 等（或使用 extra 语法）。

## 2. 第一个 Agent

```python
# pip install -qU langchain "langchain[openai]"
from langchain.agents import create_agent


def get_weather(city: str) -> str:
    """查询指定城市的天气。"""
    return f"{city} 永远是晴天！"


agent = create_agent(
    model="openai:gpt-5.5",
    tools=[get_weather],
    system_prompt="你是一个乐于助人的助手",
)

result = agent.invoke(
    {"messages": [{"role": "user", "content": "旧金山天气怎么样？"}]}
)
print(result["messages"][-1].content_blocks)
```

发生了什么：

```text
用户消息 → 模型 → 决定调用 get_weather → 执行工具 → 工具结果回灌 → 模型 → 最终回答
                        ↑__________________ 循环，直到不再调用工具 __________________|
```

## 3. 换模型只改一个字符串

`model` 参数接受 `"provider:model"` 形式的标识符：

```python
create_agent(model="openai:gpt-5.5", tools=tools)
create_agent(model="anthropic:claude-sonnet-5", tools=tools)
create_agent(model="google_genai:gemini-3.6-flash", tools=tools)
create_agent(model="ollama:llama3.3", tools=tools)
create_agent(model="openrouter:z-ai/glm-5.2", tools=tools)
create_agent(model="bedrock_converse:us.anthropic.claude-sonnet-4-6", tools=tools)
```

需要更细的配置（温度、base_url、部署名）时，先构造模型实例再传入：

```python
from langchain.chat_models import init_chat_model

model = init_chat_model(
    "azure_openai:gpt-5.5",
    azure_deployment="my-deployment",
    temperature=0.2,
)

agent = create_agent(model=model, tools=tools)
```

## 5. 项目结构建议

```text
my_agent/
├── pyproject.toml
├── agents/
│   └── researcher.py      # create_agent 定义
├── tools/
│   ├── search.py
│   └── database.py
├── middleware/
│   └── audit.py           # 自定义中间件
└── main.py                # 入口：invoke / serve
```

**分层原则**：

- `tools/`：纯函数 + docstring（模型靠 docstring 理解工具用途）。
- `agents/`：只做组装，不写业务逻辑。
- `middleware/`：横切关注点（日志、鉴权、限流、脱敏）。

## 6. 最小可运行脚本

```python
import os
from langchain.agents import create_agent
from langchain.tools import tool

os.environ.setdefault("OPENAI_API_KEY", "sk-...")


@tool
def calculate(expression: str) -> str:
    """计算一个数学表达式，例如 '2 * (3 + 4)'。"""
    return str(eval(expression, {"__builtins__": {}}, {}))


agent = create_agent(
    model="openai:gpt-5.5",
    tools=[calculate],
    system_prompt="你是一个计算助手，必须使用 calculate 工具完成运算。",
)

for chunk in agent.stream(
    {"messages": [{"role": "user", "content": "17 乘以 23 是多少？"}]},
    stream_mode="values",
):
    chunk["messages"][-1].pretty_print()
```

## 7. 常见坑

| 现象 | 原因 | 解决 |
|---|---|---|
| `Model not found` | 没装对应 provider 包 | `pip install langchain-openai` |
| 工具永远不被调用 | docstring 缺失或描述模糊 | 写清「做什么、何时用、参数含义」 |
| 输出被截断 | `max_tokens` 太小 | 调大或换长上下文模型 |
| 报 `401` | 环境变量未生效 | 检查 shell 是否新开了终端 |
| 中文乱码 | Windows 控制台编码 | `chcp 65001` 或设 `PYTHONIOENCODING=utf-8` |
