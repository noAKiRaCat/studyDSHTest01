# LangChain 05 · 中间件（Middleware）

> 中间件是 v1 最重要的扩展点。它让你在「模型调用前后」「工具调用前后」插入逻辑，而不必改写 Agent 本身。

---

## 1. 为什么需要中间件

Agent 循环里的横切关注点：

- 重试、超时、降级
- 日志、追踪、审计
- 限流、计费
- PII 脱敏、内容过滤
- 历史压缩、上下文裁剪
- 人工审批

这些东西不该混在业务工具里，也不该改 `create_agent` 的源码——所以有中间件。

---

## 2. 钩子一览

```text
         ┌──────────────┐
 请求 ──▶│ before_model │──▶ 模型 ──▶│ after_model │──▶ 响应
         └──────────────┘              └─────────────┘
              │                              │
         wrap_model_call               wrap_tool_call
         （可完全接管调用）              （可拦截工具）
```

| 钩子 | 时机 | 典型用途 |
|---|---|---|
| `before_model` | 模型调用前 | 裁剪消息、注入上下文、动态改提示词 |
| `after_model` | 模型调用后 | 解析输出、记录、修改状态 |
| `wrap_model_call` | 包裹模型调用 | 重试、限流、降级、动态换模型/工具 |
| `wrap_tool_call` | 包裹工具调用 | 鉴权、审计、缓存、异常兜底 |
| `before_agent` / `after_agent` | 整个 Agent 前后 | 初始化、收尾 |

---

## 3. 内置中间件速查

| 中间件 | 作用 |
|---|---|
| `ModelRetryMiddleware` | 模型调用失败重试（指数退避） |
| `ToolRetryMiddleware` | 工具调用失败重试 |
| `ModelFallbackMiddleware` | 主模型失败时切备用模型 |
| `SummarizationMiddleware` | 历史超长时自动摘要 |
| `HumanInTheLoopMiddleware` | 指定工具调用前暂停等人工审批 |
| `PIIMiddleware` | 邮箱/电话/信用卡等脱敏 |
| `TodoListMiddleware` | 给 Agent 一个 `write_todos` 待办工具 |
| `ModelCallLimitMiddleware` | 限制模型调用次数（防死循环） |
| `ToolCallLimitMiddleware` | 限制工具调用次数 |

### 组合示例

```python
from langchain.agents import create_agent
from langchain.agents.middleware import (
    ModelRetryMiddleware,
    ToolRetryMiddleware,
    ModelFallbackMiddleware,
    SummarizationMiddleware,
    PIIMiddleware,
    ModelCallLimitMiddleware,
)

agent = create_agent(
    model="anthropic:claude-sonnet-5",
    tools=tools,
    middleware=[
        ModelCallLimitMiddleware(max_calls=25),
        ModelFallbackMiddleware(fallback_models=["openai:gpt-5-mini"]),
        ModelRetryMiddleware(max_retries=3, initial_delay=1.0),
        ToolRetryMiddleware(max_retries=2),
        PIIMiddleware(["email", "phone"]),
        SummarizationMiddleware(max_tokens=8000),
    ],
)
```

> **顺序有讲究**：越靠外的中间件越早介入。限流放最外层，脱敏放在接近模型的位置。

## 4. 自定义中间件

### 4.1 装饰器风格（最简）

```python
from langchain.agents.middleware import before_model, after_model


@before_model
def inject_time(state, runtime):
    """每次调模型前注入当前时间。"""
    from datetime import datetime
    now = datetime.now().strftime("%Y-%m-%d %H:%M")
    return {"messages": state["messages"] + [
        {"role": "system", "content": f"当前时间：{now}"}
    ]}


@after_model
def log_output(state, runtime):
    last = state["messages"][-1]
    print(f"[审计] 模型输出 {len(last.content)} 字符")
    return None   # 不修改状态
```

### 4.2 类风格（可配置、可复用）

```python
from langchain.agents.middleware import AgentMiddleware


class AuditMiddleware(AgentMiddleware):
    """记录每次工具调用的耗时与结果。"""

    def __init__(self, logger):
        self.logger = logger

    def wrap_tool_call(self, request, handler):
        import time
        start = time.time()
        result = handler(request)
        elapsed = time.time() - start
        self.logger.info(
            "tool=%s args=%s elapsed=%.3fs",
            request.tool_call["name"],
            request.tool_call["args"],
            elapsed,
        )
        return result


agent = create_agent(model="...", tools=tools, middleware=[AuditMiddleware(logger)])
```

### 4.3 包装模型调用（最灵活）

```python
from langchain.agents.middleware import wrap_model_call
from langchain.agents.middleware.types import ModelRequest


@wrap_model_call
def route_by_difficulty(request: ModelRequest, handler):
    """简单问题用小模型，复杂问题用大模型。"""
    last = request.state["messages"][-1].text
    if len(last) < 50:
        request = request.override(model="openai:gpt-5-mini")
    return handler(request)
```

`request.override(...)` 可以改：

- `model`：换模型
- `tools`：换工具集
- `system_prompt`：换系统提示
- `messages`：换消息历史

这是「动态工具」「按租户隔离」「按成本降级」的标准做法。

## 5. 状态更新规则

中间件返回 dict 会合并进状态：

```python
{"messages": [...]}      # 追加
{"counter": 5}           # 覆盖
```

需要**累加**时用注解：

```python
from typing import Annotated
import operator

class MyState(AgentState):
    total_tokens: Annotated[int, operator.add]
```

此时中间件返回 `{"total_tokens": 100}` 表示「加 100」，而不是「设为 100」。

## 6. 实战：三个常用模式

### 6.1 内容安全阀

```python
from langchain.agents.middleware import after_model

BLOCKED = ("制作炸弹", "盗取密码")

@after_model
def safety_check(state, runtime):
    text = state["messages"][-1].text
    for kw in BLOCKED:
        if kw in text:
            raise ValueError("触发安全策略，已终止")
    return None
```

### 6.2 工具级鉴权

```python
from langchain.agents.middleware import wrap_tool_call

ADMIN_ONLY = {"delete_user", "export_all"}

@wrap_tool_call
def authorize(request, handler):
    if request.tool_call["name"] in ADMIN_ONLY and not request.runtime.context.is_admin:
        return "权限不足：该操作仅管理员可执行"
    return handler(request)
```

### 6.3 工具结果缓存

```python
import hashlib
from langchain.agents.middleware import wrap_tool_call

_cache = {}

@wrap_tool_call
def cache_tool(request, handler):
    key = hashlib.md5(
        f"{request.tool_call['name']}:{request.tool_call['args']}".encode()
    ).hexdigest()
    if key not in _cache:
        _cache[key] = handler(request)
    return _cache[key]
```

## 7. 中间件执行顺序

```python
middleware=[A, B, C]
```

```text
before_model: A → B → C → 模型
after_model : 模型 → C → B → A     （洋葱模型，反向）
```

`wrap_*` 同理：A 包 B，B 包 C。

## 8. 常见坑

| 现象 | 原因 | 解决 |
|---|---|---|
| 中间件不生效 | 传成了类而非实例 | `AuditMiddleware(logger)` 要实例化 |
| 状态被覆盖 | 用了普通字段却想累加 | 用 `Annotated[..., operator.add]` |
| 无限重试 | 重试中间件包住了不可恢复错误 | 区分可重试异常 |
| 顺序导致脱敏失效 | PII 放在最外层 | 放到靠近模型的位置 |
