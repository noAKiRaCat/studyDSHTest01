# LangGraph 04 · 流式、容错与子图

> 生产环境的三个硬需求：**过程可见（流式）**、**出错能扛（容错）**、**结构可拆（子图）**。

---

## 1. 流式输出

### 1.1 五种模式

```python
for chunk in graph.stream(inputs, stream_mode="updates"):
    print(chunk)
```

| 模式 | 输出 | 说明 |
|---|---|---|
| `values` | 每步完整状态 | 适合快照/调试 |
| `updates` | `{节点名: 更新内容}` | 适合进度条 |
| `messages` | `(消息块, 元数据)` | 适合打字机 |
| `custom` | 节点内 `StreamWriter` 写入 | 适合业务进度 |
| `debug` | 详细执行事件 | 排查用 |

### 1.2 打字机效果

```python
for msg, meta in graph.stream(inputs, stream_mode="messages"):
    if meta.get("langgraph_node") == "write":
        print(msg.content, end="", flush=True)
```

按节点过滤，避免把内部节点的草稿也吐给用户。

### 1.3 自定义事件

```python
from langgraph.config import get_stream_writer

def long_node(state):
    writer = get_stream_writer()
    for i, item in enumerate(state["items"]):
        writer({"stage": "processing", "index": i, "total": len(state["items"])})
    return {"done": True}

for ev in graph.stream(inputs, stream_mode="custom"):
    print(ev)   # {'stage': 'processing', 'index': 0, ...}
```

### 1.4 多模式并行订阅

```python
for mode, chunk in graph.stream(inputs, stream_mode=["updates", "messages"]):
    if mode == "updates":
        ...
    else:
        ...
```

### 1.5 异步

```python
async for chunk in graph.astream(inputs, stream_mode="messages"):
    ...
```

## 2. 容错

### 2.1 节点级重试

```python
builder.add_node(
    "call_api",
    call_api,
    retry_policy={
        "max_attempts": 3,
        "initial_interval": 0.5,   # 秒
        "backoff_factor": 2.0,
        "jitter": True,
    },
)
```

### 2.2 节点级超时

```python
builder.add_node("slow", slow_node, timeout=30)   # 秒
```

### 2.3 错误处理分支

```python
def safe_node(state):
    try:
        return {"result": risky()}
    except Exception as e:
        return {"error": str(e), "result": None}


def route(state):
    return "recover" if state.get("error") else END
```

把失败变成状态里的一条数据，交给图去处理，而不是让整张图崩掉。

### 2.4 幂等设计

持久化 + 重试要求节点可重复执行：

```python
def charge_card(state):
    key = state["idempotency_key"]          # 由上游生成
    if already_charged(key):
        return {"charged": True}
    do_charge(key, state["amount"])
    return {"charged": True}
```

## 3. 子图

### 3.1 把图当节点

```python
sub_graph = sub_builder.compile()
builder.add_node("research", sub_graph)
```

父子图状态兼容时自动传参；不兼容就显式映射：

```python
builder.add_node(
    "research",
    sub_graph,
    input_schema=ParentToChild,
    output_schema=ChildToParent,
)
```

### 3.2 状态隔离

子图默认有自己的命名空间，检查点独立。跨子图共享数据靠**显式读写父状态**。

### 3.3 何时用子图

| 场景 | 收益 |
|---|---|
| 可复用的流程（如「检索 + 归纳」） | 一次定义多处调用 |
| 团队分工 | 各自维护自己的图 |
| 不同持久化策略 | 子图可单独配 checkpointer |
| 可视化降噪 | 主图保持高层流程 |

## 4. 部署

### 4.1 本地运行

```bash
pip install langgraph-cli
langgraph dev          # 启动本地开发服务器 + Studio
```

`langgraph.json` 配置：

```json
{
  "dependencies": ["."],
  "graphs": {
    "agent": "./src/agent.py:graph"
  },
  "env": ".env"
}
```

### 4.2 生产部署选项

| 方式 | 说明 |
|---|---|
| **LangSmith Deployment** | 托管服务，自动扩缩容、可观测性 |
| 自建容器 | 用 `langgraph serve` 打包成 HTTP 服务 |
| Serverless | 适配长连接的平台需注意超时 |

### 4.3 服务化要点

```text
POST /threads                   创建会话
POST /threads/{id}/runs         启动运行（可流式 SSE）
GET  /threads/{id}/state        查询状态
POST /threads/{id}/runs/{rid}/resume  恢复中断
```

- **会话 ID 由服务端管理**，前端只需保存。
- **长任务用 SSE/WebSocket**，别用同步 HTTP 等结果。
- **中断恢复**要走专门的 resume 接口。

## 6. 性能优化清单

| 优化点 | 做法 |
|---|---|
| 减少串行等待 | 并行分支 + `Send` |
| 降低 token | 状态里只放必要字段；长文本外置 |
| 降低延迟 | 简单节点用小模型；缓存重复调用 |
| 减少检查点开销 | 高频小步骤可合并；大状态用引用 |
| 提升吞吐 | 异步节点 + 连接池 |

## 7. 完整生产骨架

```python
from langgraph.graph import StateGraph, START, END
from langgraph.checkpoint.postgres import PostgresSaver
from langgraph.store.postgres import PostgresStore

builder = StateGraph(State)
builder.add_node("plan", plan_node, retry_policy={"max_attempts": 2})
builder.add_node("act", act_node, timeout=60)
builder.add_node("review", review_node)
builder.add_edge(START, "plan")
builder.add_edge("plan", "act")
builder.add_edge("act", "review")
builder.add_conditional_edges("review", should_retry, {"act": "act", END: END})

with PostgresSaver.from_conn_string(DSN) as saver, \
     PostgresStore.from_conn_string(DSN) as store:
    saver.setup()
    store.setup()
    graph = builder.compile(checkpointer=saver, store=store)

    graph.invoke(inputs, {"configurable": {"thread_id": tid}, "recursion_limit": 50})
```

## 8. 常见坑

| 现象 | 原因 | 解决 |
|---|---|---|
| 流式无输出 | 节点是同步阻塞调用 | 用异步客户端 |
| 重试导致重复副作用 | 节点不幂等 | 幂等键 |
| 子图状态丢失 | 没传 `thread_id` 或命名空间冲突 | 检查 config 传递 |
| 部署后中断失效 | 用了内存 checkpointer | 换 Postgres |
| 超时被平台杀掉 | 平台请求超时 | 改异步任务 + 轮询 |
