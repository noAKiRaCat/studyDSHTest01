# Deep Agents 01 · 总览与快速开始

> Deep Agents 是一个**成品 Agent 骨架（harness）**：开箱就带规划、虚拟文件系统、子代理、技能与记忆。它构建在 LangChain 与 LangGraph 之上。

---

## 1. 它比 create_agent 多了什么

`create_agent` 只给你「模型 + 工具 + 中间件」的循环。做长任务时你会发现缺：

| 缺什么 | 后果 | Deep Agents 的方案 |
|---|---|---|
| 规划 | 模型做着做着忘了目标 | `write_todos` 待办工具 |
| 上下文管理 | 几十轮后爆上下文 | 摘要压缩 + 大结果卸载到文件 |
| 文件操作 | 中间产物没地方放 | 虚拟文件系统（ls/read/write/edit/glob/grep） |
| 并行 | 串行慢 | 子代理 `task` |
| 领域知识 | 提示词越写越长 | 技能（SKILL.md 按需加载） |
| 跨会话记忆 | 每次从零开始 | `AGENTS.md` 长期记忆 |

## 3. 十行起步

```python
from deepagents import create_deep_agent


def get_weather(city: str) -> str:
    """查询指定城市的天气。"""
    return f"{city} 永远是晴天！"


agent = create_deep_agent(
    model="openai:gpt-5.5",
    tools=[get_weather],
    system_prompt="你是一个乐于助人的助手",
)

agent.invoke({"messages": [{"role": "user", "content": "旧金山天气如何？"}]})
```

就这一行 `create_deep_agent`，你已经得到了：

- 文件系统工具（`ls` / `read_file` / `write_file` / `edit_file` / `glob` / `grep`）
- 子代理 `task` 工具
- 上下文压缩与卸载
- （v0.7 起需显式开启）待办清单

## 4. 四种能力分区

官方把 harness 能力分成四块：

```text
┌─────────────────────────────────────────────┐
│ 执行环境   工具 / 虚拟文件系统 / 权限 / 代码执行 │
├─────────────────────────────────────────────┤
│ 上下文管理 技能 / 记忆 / 摘要压缩 / 提示缓存     │
├─────────────────────────────────────────────┤
│ 委派       任务规划 / 子代理                    │
├─────────────────────────────────────────────┤
│ 引导       人在环审批 / 中断                    │
└─────────────────────────────────────────────┘
```

## 5. 内置文件工具

| 工具 | 作用 |
|---|---|
| `ls` | 列目录（含大小、修改时间） |
| `read_file` | 读文件（带行号，支持 offset/limit；支持图片/PDF 等多模态） |
| `write_file` | 新建或覆盖 |
| `edit_file` | 精确字符串替换 |
| `delete` | 删除文件/目录（需 `deepagents>=0.7`） |
| `glob` | 按模式找文件（`**/*.py`） |
| `grep` | 搜内容（仅文件名 / 带上下文 / 计数） |
| `execute` | 执行 shell（仅沙箱后端可用） |

**多模态读取**支持：

- 图片：`.png .jpg .jpeg .gif .webp .heic .heif`
- 视频：`.mp4 .mov .avi .webm ...`
- 音频：`.wav .mp3 .ogg .flac ...`
- 文档：`.pdf .ppt .pptx`

## 6. 任务规划（v0.7 起需显式开启）

```python
from deepagents import create_deep_agent
from langchain.agents.middleware import TodoListMiddleware

agent = create_deep_agent(
    model="openai:gpt-5.5",
    middleware=[TodoListMiddleware()],
)
```

开启后模型多了一个 `write_todos` 工具，任务状态为 `pending` / `in_progress` / `completed`，并写入 Agent 状态，前端可以据此渲染进度。

**什么任务适合开**：

- 多步骤、长流程
- 能力较弱的模型（给它一个「记账」工具）
- 需要向前端展示进度

## 7. 子代理

内置 `task` 工具，主代理可以把子任务丢给子代理：

```python
from deepagents import create_deep_agent

agent = create_deep_agent(
    model="openai:gpt-5.5",
    subagents=[
        {
            "name": "researcher",
            "description": "负责网络调研，返回结构化摘要",
            "system_prompt": "你是研究员，用 search 工具调研并总结要点。",
            "tools": [search],
            "model": "anthropic:claude-sonnet-5",
        }
    ],
)
```

两种运行模式：

| 模式 | 行为 |
|---|---|
| 同步（默认） | 阻塞主代理，返回一份报告 |
| 异步 | 后台并行，支持 `launch` / `check` / `update` / `cancel` |

两种上下文模式：

| `mode` | 行为 |
|---|---|
| `isolated`（默认） | 全新上下文，只看得到任务描述 |
| `fork` | 继承父代理完整对话历史 |

## 8. 技能与记忆

### 技能（Skills）

按 `SKILL.md` 组织的知识包，**渐进式披露**：启动时只读 frontmatter，需要时才读全文。

```text
skills/
└── pdf-report/
    ├── SKILL.md
    ├── template.docx
    └── examples/
```

### 记忆（Memory）

`AGENTS.md` 文件，**始终加载**，用于项目规范、编码风格、用户偏好。

```python
agent = create_deep_agent(
    model="openai:gpt-5.5",
    memory=["./AGENTS.md"],
)
```

## 9. 提示缓存（自动）

使用 Anthropic 或 Amazon Bedrock（Claude / Nova）时，`create_deep_agent` 会自动对系统提示的静态部分（基础指令、记忆、技能内容）启用提示缓存，降低长任务的延迟与成本，无需配置。

其他供应商可接入对应的缓存中间件。

## 10. 自托管 vs 托管

| 方式 | 说明 |
|---|---|
| **Managed Deep Agents** | LangSmith 托管，运行 harness、Agent Server、沙箱、定时任务 |
| **Deep Agents SDK** | 自己托管进程/容器，最大灵活性 |
| **LangSmith Deployment** | 自定义部署配置 |

本文档主要讲 SDK 自托管。

---

## 11. 常见坑

| 现象 | 原因 | 解决 |
|---|---|---|
| 没有待办工具 | v0.7 起默认关闭 | 显式加 `TodoListMiddleware` |
| 文件写到意想不到的位置 | 后端默认是内存态 | 换 `FilesystemBackend` 指定根目录 |
| 子代理看不到上下文 | 默认 `isolated` | 需要共享用 `mode: "fork"` |
| token 消耗大 | 记忆/技能太长 | 精简 `AGENTS.md`，技能按需拆分 |
