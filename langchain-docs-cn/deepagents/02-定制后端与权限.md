# Deep Agents 02 · 定制、后端与权限

> 虚拟文件系统是 Deep Agents 的核心。它决定了 Agent 能看见什么、能改什么、能把中间产物放在哪。

---

## 1. `create_deep_agent` 参数

| 参数 | 说明 |
|---|---|
| `model` | 模型标识或实例 |
| `tools` | 自定义工具列表 |
| `system_prompt` | 系统提示 |
| `middleware` | 附加中间件（会叠加在默认栈之上） |
| `subagents` | 子代理定义列表 |
| `backend` | 文件系统后端 |
| `permissions` | 声明式权限规则 |
| `memory` | `AGENTS.md` 路径列表 |
| `interrupt_on` | 需要人工审批的工具映射 |
| `checkpointer` | 持久化实现 |

---

## 2. 默认中间件栈

```text
FilesystemMiddleware   ← 文件工具（必需，不能整体移除）
SubAgentMiddleware     ← task 工具
SummarizationMiddleware← 上下文压缩
（可选）TodoListMiddleware
（可选）自定义中间件
```

**注意**：`FilesystemMiddleware` 是必需脚手架，官方明确拒绝通过 `excluded_middleware` 移除它。要「关掉文件能力」，应该用工具白名单/黑名单。

---

## 3. 后端（Backend）

后端决定文件到底存在哪。

| 后端 | 存储位置 | 适用 |
|---|---|---|
| `StateBackend` | Agent 状态（内存） | 开发、临时 |
| `FilesystemBackend` | 真实磁盘 | 需要持久化到本地 |
| `StoreBackend` | LangGraph Store | 多会话共享 |
| 复合路由后端 | 按路径分发到不同后端 | 混合场景 |
| 自定义后端 | 你自己实现 | 对接对象存储/S3 |

### 3.1 内存态（默认）

```python
from deepagents import create_deep_agent
from deepagents.backends import StateBackend

agent = create_deep_agent(
    model="openai:gpt-5.5",
    backend=StateBackend(),
)
```

进程结束即消失，适合测试。

### 3.2 本地磁盘

```python
from deepagents.backends import FilesystemBackend

agent = create_deep_agent(
    model="openai:gpt-5.5",
    backend=FilesystemBackend(root_dir="./workspace"),
)
```

### 3.3 复合路由

不同路径走不同后端，例如 `/memories/` 走 Store，其他走磁盘：

```python
from deepagents.backends import CompositeBackend, FilesystemBackend, StoreBackend

backend = CompositeBackend(
    default=FilesystemBackend(root_dir="./workspace"),
    routes={
        "/memories/": StoreBackend(store=store),
    },
)
```

## 4. 权限（Permissions）

声明式规则，**按顺序匹配，先命中先生效**，都没命中则允许。

```python
agent = create_deep_agent(
    model="openai:gpt-5.5",
    permissions=[
        {"operations": ["read"], "paths": ["/workspace/**"], "mode": "allow"},
        {"operations": ["write"], "paths": ["/workspace/out/**"], "mode": "allow"},
        {"operations": ["write"], "paths": ["/workspace/**"], "mode": "deny"},
        {"operations": ["read", "write"], "paths": ["**/.env", "**/credentials*"], "mode": "deny"},
    ],
)
```

字段说明：

| 字段 | 取值 | 说明 |
|---|---|---|
| `operations` | `"read"` / `"write"` | 可组合 |
| `paths` | glob 模式 | 文件或目录 |
| `mode` | `"allow"` / `"deny"` | 默认 allow |

**典型策略**：只读区 + 可写输出区 + 敏感文件全禁。

```text
/workspace/docs/**    read only
/workspace/out/**     read + write
/workspace/secrets/** deny all
```

> 权限只作用于**内置文件工具**，不约束沙箱后端的 `execute`（沙箱里可以跑任意命令）。要更细的控制，用后端的 policy hook。

## 5. 工具可见性控制

### 5.1 全部隐藏（保留中间件）

```python
from deepagents import HarnessProfile, register_harness_profile

register_harness_profile(
    "anthropic:claude-sonnet-4-6",
    HarnessProfile(
        excluded_tools=frozenset(
            {"ls", "read_file", "write_file", "edit_file", "delete", "glob", "grep"}
        ),
    ),
)
```

### 5.2 只给一部分（白名单）

```python
from deepagents.middleware import FilesystemMiddleware

agent = create_deep_agent(
    model="openai:gpt-5.5",
    middleware=[
        FilesystemMiddleware(
            backend=backend,
            tools=["read_file", "ls", "glob", "grep"],   # 只读代理
        ),
    ],
)
```

规则：

- `read_file` **必须**在白名单里，否则创建时报 `ValueError`。
- `execute` / `delete` 在后端不支持时会被自动隐藏。
- 通过 `create_deep_agent(tools=...)` 传入的自定义工具不受此白名单影响。
- 主代理的自定义 `FilesystemMiddleware` 会被通用子代理继承；声明式子代理需各自配置。

## 6. 定制系统提示与技能

```python
agent = create_deep_agent(
    model="openai:gpt-5.5",
    system_prompt="""你是一名资深后端工程师。
规则：
1. 先用 write_todos 列出计划
2. 改动前先 read_file 确认现状
3. 完成后跑测试并把结果写进 /out/report.md
""",
)
```

技能目录（`SKILL.md`）：

```markdown

name: pdf-report

2. 调用 make_chart 生成图
3. 使用 template.docx 填充内容
4. 输出到 /out/weekly.pdf
```

## 7. 自定义后端（进阶）

实现后端协议即可对接任意存储：

```python
from deepagents.backends import BaseBackend


class S3Backend(BaseBackend):
    def read(self, path: str) -> str:
        return s3.get_object(Bucket=BUCKET, Key=path)["Body"].read().decode()

    def write(self, path: str, content: str) -> None:
        s3.put_object(Bucket=BUCKET, Key=path, Body=content.encode())

    def list(self, path: str):
        ...
```

可在此层加：审计日志、病毒扫描、配额限制、加密。

## 8. 常见坑

| 现象 | 原因 | 解决 |
|---|---|---|
| Agent 说「找不到文件」 | 后端是内存态，重启丢了 | 换 `FilesystemBackend` / `StoreBackend` |
| 权限规则不生效 | 只写了 deny 没写 allow，顺序不对 | 先写具体规则，再写兜底 |
| 白名单报错 | `read_file` 被排除 | 必须包含 |
| 沙箱里能读敏感文件 | 权限不管 `execute` | 用沙箱自身的文件系统隔离 |
